# Security Policy

## Supported Versions

| Version | Supported          |
| :------ | :----------------- |
| 1.5.x   | :white_check_mark: |
| < 1.5   | :x:                |

---

## Reporting a Vulnerability

If you discover a security issue or vulnerability in **PortView**, please report it responsibly:

1. **Do not create a public issue**.
2. Open a private security advisory on GitHub under the **Security** tab, or email the repository maintainers.
3. Include details of the vulnerability, reproduction steps, and potential impact.

We will review reports promptly and publish patches with appropriate security advisories.
